# Agent Skills Directory

Place your custom agent skills in this folder.

### Skill Folder Structure:
Each skill must have its own subfolder containing a `SKILL.md` file:
```
.agents/skills/
├── <skill-name>/
│   └── SKILL.md
```

### Example `SKILL.md` Format:
```markdown
---
name: skill-name
description: Clear 1-2 sentence description of when and why this skill is activated.
---

# Instructions
Detailed guidelines, best practices, code snippets, or rules for the agent to follow.
```
